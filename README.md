# Star Wars Directory

A Next.js application to browse and search for Star Wars characters.

> [!NOTE]
> This project was originally a Create React App using JavaScript and has been ported to Next.js and TypeScript.

## Features

- **Character Directory**: Browse through all Star Wars characters with pagination.
- **Search**: Search for characters by name.
- **Character Details**: View details like gender, birth year, and more on portrait cards.
- **Responsive Design**: Works on desktop and mobile.

## API Reference

This project uses the [Star Wars API (SWAPI)](https://swapi.dev/).

- **Characters**: `https://swapi.dev/api/people/`
  - Used for listing all characters and searching by name.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
